Dracula by Phantom is a dark palette: the terminal sits on `#282a36` and writes in `#f8f8f2`, a contrast ratio of 13.4:1. All 16 ANSI entries are different colours. A selection is drawn on `#44475a`.

The extension holds one file of colour settings and nothing else. It installs no
program, starts no process and asks for no approval. Install it, pick it in
Settings, and that is all it does.

Phantom already ships Ghostty's Dracula, and that theme sets the sixteen terminal colours, the background, the foreground, the cursor and the selection. This one sets those to the same values, from the same specification, and then keeps going: the divider between splits, the unfocused half of a split, the search bar, the window title bar, and the ghost and screen of the macOS app icon. That is the reason to install it, and the reason it carries a different name — both appear in the theme picker, and picking the wrong one is a real mistake to be able to avoid.

## Getting started

<Steps>
  <Step title="Install the extension">
    In Phantom, open the Extensions pane in the sidebar (or Settings → Extensions) and press **Install** next to Dracula by Phantom.
  </Step>
  <Step title="Open Settings → Appearance">
    Themes from extensions are listed under **Extension Themes**, above the Dark and Light groups. The theme in use gets its own card at the top of the page.
  </Step>
  <Step title="Pick Dracula by Phantom">
    Press its card. The change applies to every window at once, with no restart.
  </Step>
  <Step title="Tell it apart from the built-in Dracula">
    The Dark group also holds **Dracula** and **Dracula+**, which ship with Phantom. Those two set the terminal colours only. The card under Extension Themes is this one.
  </Step>
</Steps>

## What the extension adds

| Area | Contribution |
|---|---|
| Theme | Dracula by Phantom, dark |
| Terminal | 16 ANSI colours, background, foreground, bold, cursor and cursor text |
| Selection | Selection background and foreground |
| Splits | Divider colour, and the fill behind an unfocused split |
| Search | Background and foreground of a match, and of the selected match |
| Window | Title bar background and foreground |
| App icon | Ghost colour and screen colour of the macOS icon |
| Programs | none |

## Configuration

<Details summary="The window colours">

The panel above covers the terminal. These eleven keys carry the palette into the rest of the app,
and every value is a colour the specification already names.

| Key | Colour | Dracula name |
|---|---|---|
| `bold-color` | `#ffffff` | ANSI Bright White |
| `split-divider-color` | `#44475a` | Selection |
| `unfocused-split-fill` | `#21222c` | ANSI Black |
| `search-background` | `#f1fa8c` | Yellow |
| `search-foreground` | `#282a36` | Background |
| `search-selected-background` | `#ffb86c` | Orange |
| `search-selected-foreground` | `#282a36` | Background |
| `window-titlebar-background` | `#21222c` | ANSI Black |
| `window-titlebar-foreground` | `#f8f8f2` | Foreground |
| `macos-icon-ghost-color` | `#bd93f9` | Purple |
| `macos-icon-screen-color` | `#282a36` | Background |

Orange is the one specification colour outside the ANSI sixteen, and it marks the search match you
are standing on. Text on either search highlight is drawn in the background colour, at 12.7:1 and
8.4:1.

</Details>

<Details summary="The theme file">

The whole extension is `themes/dracula.conf`. It is a Ghostty theme file: one `key = value` per line, `#` for comments, and colour keys only.

```ini
background = #282a36
foreground = #f8f8f2
palette = 4=#bd93f9

selection-background = #44475a
split-divider-color = #44475a
search-background = #f1fa8c
search-selected-background = #ffb86c
window-titlebar-background = #21222c
macos-icon-ghost-color = #bd93f9
```

Phantom accepts `background`, `foreground`, `palette`, `cursor-color`, `cursor-text`, `selection-background`, `selection-foreground`, `bold-color`, `split-divider-color`, `unfocused-split-fill`, the four `search-*` keys, the two `window-titlebar-*` keys and the two `macos-icon-*` keys. A file that sets anything else is dropped whole rather than partly applied, and it may not exceed 64 KB.

</Details>

<Details summary="Making your own copy">

Settings → Extensions has a **Reveal in Finder** button. Copy `themes/dracula.conf`, change what you want, and either point a new entry in `extension.json` at it or drop the file into your own themes folder, where Settings → Appearance lists it under **Custom Themes**.

An extension theme is selected by its file path rather than by its name, so a custom copy never collides with this one.

</Details>

## Troubleshooting

<Details summary="Two cards are called Dracula">

Three, in fact: **Dracula** and **Dracula+** ship with Phantom and sit in the Dark group, and **Dracula by Phantom** is this one, under Extension Themes. The names differ so the cards can be told apart, because Phantom lists bundled and contributed themes side by side.

</Details>

<Details summary="The theme is not in the list">

Phantom drops a contributed theme whose file sets a key that is not a colour, whose file is larger than 64 KB, or whose name is already taken by a bundled or custom theme. Settings → Extensions lists what the manifest contributed, which is where a dropped theme shows up as missing.

</Details>

<Details summary="The title bar or the app icon did not change">

Those two keys reach the window chrome and the macOS icon, which some system settings override. The terminal colours apply immediately in every case; the chrome follows the window's own appearance.

</Details>

<Details summary="Text printed in ANSI black is hard to read">

ANSI Black is `#21222c`, which sits 1.11:1 against the background. That is the specification's own
value, and Ghostty's Dracula uses it too. A program that prints in ANSI 0 on the default background
is close to invisible here. The theme does not correct it, because a correction would stop the two
Dracula themes matching.

</Details>
