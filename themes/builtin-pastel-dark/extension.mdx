Builtin Pastel Dark is a dark palette: the terminal sits on `#000000` and writes in `#bbbbbb`, a contrast ratio of 10.9:1. All 16 ANSI entries are different colours. A selection is drawn on `#363983`.

The extension holds one file of colour settings and nothing else. It installs no
program, starts no process and asks for no approval. Install it, pick it in
Settings, and that is all it does.

## Getting started

<Steps>
  <Step title="Install the extension">
    In Phantom, open the Extensions pane in the sidebar (or Settings → Extensions) and press **Install** next to Builtin Pastel Dark.
  </Step>
  <Step title="Open Settings → Appearance">
    Themes from extensions are listed under **Extension Themes**, above the Dark and Light groups. The theme in use gets its own card at the top of the page.
  </Step>
  <Step title="Pick Builtin Pastel Dark">
    Press its card. The change applies to every window at once, with no restart.
  </Step>
  <Step title="Keep it, or go back">
    The Dark group still holds every theme that ships with Phantom, so returning is one more card press. Nothing here is written over.
  </Step>
</Steps>

## Configuration

<Details summary="The theme file">

The whole extension is `themes/builtin-pastel-dark.conf`. It is a Ghostty theme file: one `key = value` per line, `#` for comments, and colour keys only. This one sets 22 values.

```ini
palette = 0=#4f4f4f
palette = 1=#ff6c60
palette = 2=#a8ff60
palette = 3=#ffffb6
palette = 4=#96cbfe
palette = 5=#ff73fd
palette = 6=#c6c5fe
palette = 7=#eeeeee
palette = 8=#7c7c7c
palette = 9=#ffb6b0
palette = 10=#ceffac
palette = 11=#ffffcc
palette = 12=#b5dcff
palette = 13=#ff9cfe
palette = 14=#dfdffe
palette = 15=#ffffff
background = #000000
foreground = #bbbbbb
cursor-color = #ffa560
cursor-text = #ffffff
selection-background = #363983
selection-foreground = #f2f2f2
```

It sets the terminal's own colours and nothing else: the divider between splits, the search bar, the window title bar and the macOS app icon keep the colours the app gives them.

Phantom accepts `background`, `foreground`, `palette`, `cursor-color`, `cursor-text`, `selection-background`, `selection-foreground`, `bold-color`, `split-divider-color`, `unfocused-split-fill`, the four `search-*` keys, the two `window-titlebar-*` keys and the two `macos-icon-*` keys. A file that sets anything else is dropped whole rather than partly applied, and it may not exceed 64 KB.

</Details>

<Details summary="Making your own copy">

Settings → Extensions has a **Reveal in Finder** button. Copy `themes/builtin-pastel-dark.conf`, change what you want, and drop the file into your own themes folder, where Settings → Appearance lists it under **Custom Themes**.

An extension theme is selected by its file path rather than by its name, so a custom copy never collides with this one, and uninstalling the extension does not take your copy with it.

</Details>

## Troubleshooting

<Details summary="The theme is not in the list">

Phantom drops a contributed theme whose file sets a key that is not a colour, whose file is larger than 64 KB, or whose name is already taken by a bundled or custom theme. Settings → Extensions lists what the manifest contributed, which is where a dropped theme shows up as missing.

</Details>

<Details summary="The title bar and the app icon did not change">

Builtin Pastel Dark is a terminal palette. It sets the sixteen ANSI colours, the background and the foreground, and it stops there, so the window chrome and the macOS icon keep the colours the app gives them and follow the window's own appearance.

</Details>
