Lua support for the Phantom editor. The extension teaches Phantom the language — file types, keywords, comments and long strings — and connects two tools that are already standard in the Lua ecosystem: **lua-language-server** for diagnostics, hover, completion and navigation, and **StyLua** for formatting. Both are optional: highlighting works the moment the extension is installed.

## Highlights

<Features columns="3">
  <Feature title="Syntax highlighting" icon="brush">
    Keywords, strings including `[[long strings]]` with any `=` level, numbers, function calls and `::labels::`. Comments with `--` and `--[[ ]]`.
  </Feature>
  <Feature title="Language intelligence" icon="search">
    Diagnostics as you type, hover documentation, completion for the standard library and your own modules, go to definition and find references.
  </Feature>
  <Feature title="Formatting" icon="sparkles">
    StyLua formats on demand or on save. The buffer is passed on stdin with `--stdin-filepath`, so the project's `stylua.toml` is honoured.
  </Feature>
</Features>

## Requirements

Phantom does not bundle the tools. Install the ones you want; the extension detects them on your `PATH`.

<Requirement command="lua-language-server" install="brew install lua-language-server" url="https://luals.github.io/">
Powers diagnostics, hover, completion and navigation. Without it the highlighter still works.
</Requirement>

<Requirement command="stylua" install="brew install stylua" url="https://github.com/JohnnyMorganz/StyLua">
Powers formatting. Without it the Format command and Format on Save do nothing for Lua files.
</Requirement>

## Getting started

<Steps>
  <Step title="Install the extension">
    In Phantom, open the Extensions pane in the sidebar (or Settings → Extensions) and press **Install** next to Lua.
  </Step>
  <Step title="Install the tools">
    Run the two Homebrew commands above. Phantom picks them up without a restart.
  </Step>
  <Step title="Open a Lua file">
    The first time a project needs lua-language-server, Phantom asks before starting it and remembers your answer for that extension.
  </Step>
  <Step title="Format">
    Press <Kbd>⌘</Kbd> <Kbd>⇧</Kbd> <Kbd>F</Kbd> to format the current file, or turn on Format on Save under Settings → Editor.
  </Step>
</Steps>

## What the extension adds

| Area | Contribution |
|---|---|
| File types | `.lua`, `.luacheckrc` |
| Language server | `lua-language-server` (stdio) |
| Formatter | `stylua --stdin-filepath <file> -` |
| Editor | Keywords, comment markers, long-string and label patterns |
| Icon | Lua file icon in the sidebar and tabs |

## Configuration

<Details summary="Language server: .luarc.json">

Place a `.luarc.json` at the root of your project to set the runtime and the libraries the server should know about.

```json
{
  "runtime.version": "Lua 5.4",
  "workspace.library": ["lib", "vendor"],
  "diagnostics.globals": ["vim", "describe", "it"]
}
```

The server reads the file on its own; Phantom passes the project root as the workspace.

</Details>

<Details summary="Formatter: stylua.toml">

StyLua looks for `stylua.toml` (or `.stylua.toml`) from the file's directory upward.

```toml
column_width = 100
indent_type = "Spaces"
indent_width = 2
quote_style = "AutoPreferDouble"
```

</Details>

## Troubleshooting

<Details summary="The editor says lua-language-server or stylua is not installed">

The bar above the file shows the install command. After installing with Homebrew, press **Check Again**; the tool must be on the `PATH` of your login shell.

</Details>

<Details summary="No diagnostics or completion in a file">

Phantom starts the server for the project containing the file. A file that lives outside any repository is opened without a workspace, which keeps the server from scanning your home folder; diagnostics still work for that file, but cross-file navigation does not.

</Details>

<Details summary="Formatting did nothing">

Formatting requires `stylua` on the `PATH`. If the file is inside a project with a `stylua.toml` that excludes it, StyLua returns the buffer unchanged.

</Details>

<Callout kind="note" title="Permissions">
The tools run as your user, with access to your files and network, the same as if you started them from the terminal. Phantom asks before it runs a program from an extension for the first time, and asks again if the extension's manifest or the program's path changes. You can review or change the answer under Settings → Extensions.
</Callout>
