Lua support for the Phantom editor. The extension teaches Phantom the language — file types, keywords, comments and long strings — and connects the two tools the Lua ecosystem has settled on: **lua-language-server** ([LuaLS](https://luals.github.io/)) for diagnostics, hover, completion and navigation, and **StyLua** for deterministic formatting. Both are optional: highlighting works the moment the extension is installed.

Supports Lua 5.1, 5.2, 5.3, 5.4, 5.5 and LuaJIT through the language server; StyLua additionally formats Luau.

## Highlights

<Showcase>
  <Features>
    <Feature title="Syntax highlighting" icon="brush">
      Keywords, strings including `[[long strings]]` with any `=` level, numbers, function calls and `::labels::`. Comments with `--` and `--[[ ]]`.
    </Feature>
    <Feature title="Language intelligence" icon="search">
      Diagnostics and syntax checking as you type, dynamic type checking, hover documentation, autocompletion for the standard library and your modules, go to definition and find references. Over 20 annotations (`---@param`, `---@return`, `---@class`) document your code and drive the checker.
    </Feature>
    <Feature title="Formatting" icon="sparkles">
      StyLua parses the file and prints it back from scratch, so the style is consistent and independent of the input. Format on demand or on save; the buffer goes in on stdin with `--stdin-filepath`, so the project's `stylua.toml` and `.styluaignore` apply.
    </Feature>
  </Features>
  <Screenshot src="media/editor.png" alt="A Lua file open in Phantom with highlighted keywords, a long string and one diagnostic from lua-language-server" caption="Highlighting, hover and a diagnostic in the Phantom editor" />
</Showcase>

## Requirements

Phantom does not bundle the tools. Install the ones you want; the extension detects them on your `PATH`.

<Requirement command="lua-language-server" install="brew install lua-language-server" url="https://luals.github.io/wiki/">
The LuaLS server: diagnostics, type checking, hover, completion, definitions, references and rename. Without it the highlighter still works. Telemetry was removed from the server in v3.6.5.
</Requirement>

<Requirement command="stylua" install="brew install stylua" url="https://github.com/JohnnyMorganz/StyLua">
The formatter. Without it the Format command and Format on Save do nothing for Lua files.
</Requirement>

## Getting started

<Steps>
  <Step title="Install the extension">
    In Phantom, open the Extensions pane in the sidebar (or Settings → Extensions) and press **Install** next to Lua.
  </Step>
  <Step title="Install the tools">
    Run the two Homebrew commands above. Phantom picks them up without a restart.
  </Step>
  <Step title="Open a Lua file">
    The first time a project needs lua-language-server, Phantom asks before starting it and remembers your answer for that extension.
  </Step>
  <Step title="Format">
    Press <Kbd>⌘</Kbd> <Kbd>⇧</Kbd> <Kbd>F</Kbd> to format the current file, or turn on Format on Save under Settings → Editor.
  </Step>
</Steps>

## What the extension adds

| Area | Contribution |
|---|---|
| File types | `.lua`, `.luacheckrc` |
| Language server | `lua-language-server` (stdio) |
| Formatter | `stylua --stdin-filepath <file> -` |
| Editor | Keywords, comment markers, long-string and label patterns |
| Icon | Lua file icon in the sidebar and tabs |

## Configuration

<Details summary="Language server: .luarc.json">

Place a `.luarc.json` at the root of your project. The server reads it on its own; Phantom passes the project root as the workspace.

```json
{
  "runtime.version": "Lua 5.4",
  "workspace.library": ["lib", "vendor"],
  "workspace.checkThirdParty": false,
  "diagnostics.globals": ["vim", "describe", "it"],
  "hint.enable": true
}
```

| Setting | What it does |
|---|---|
| `runtime.version` | `Lua 5.1` … `Lua 5.5`, `LuaJIT`; drives the standard library and the checker |
| `workspace.library` | Extra directories whose files are loaded for completion and types |
| `diagnostics.globals` | Names the checker must not report as undefined |
| `diagnostics.disable` | Diagnostic codes to silence project-wide |
| `workspace.checkThirdParty` | Turns the third-party library prompt off |

The full list is in the [LuaLS settings reference](https://luals.github.io/wiki/settings/).

</Details>

<Details summary="Formatter: stylua.toml">

StyLua looks for `stylua.toml` or `.stylua.toml` from the file's directory upward, and falls back to `.editorconfig`.

```toml
column_width = 100
line_endings = "Unix"
indent_type = "Spaces"
indent_width = 2
quote_style = "AutoPreferDouble"
call_parentheses = "Always"
collapse_simple_statement = "Never"
```

| Option | Default | Values |
|---|---|---|
| `syntax` | `All` | `All`, `Lua51`…`Lua54`, `LuaJIT`, `Luau` |
| `column_width` | `120` | integer |
| `indent_type` | `Tabs` | `Tabs`, `Spaces` |
| `indent_width` | `4` | integer |
| `quote_style` | `AutoPreferDouble` | `AutoPreferDouble`, `AutoPreferSingle`, `ForceDouble`, `ForceSingle` |
| `call_parentheses` | `Always` | `Always`, `NoSingleString`, `NoSingleTable`, `None`, `Input` |
| `collapse_simple_statement` | `Never` | `Never`, `FunctionOnly`, `ConditionalOnly`, `Always` |

Files matched by `.styluaignore` are left as they are.

</Details>

## Troubleshooting

<Details summary="The editor says lua-language-server or stylua is not installed">

The bar above the file shows the install command. After installing with Homebrew, press **Check Again**; the tool must be on the `PATH` of your login shell.

</Details>

<Details summary="No diagnostics or completion in a file">

Phantom starts the server for the project containing the file. A file that lives outside any repository is opened without a workspace, which keeps the server from scanning your home folder; diagnostics still work for that file, but cross-file navigation does not.

</Details>

<Details summary="Formatting did nothing">

Formatting requires `stylua` on the `PATH`. If the file is inside a project with a `stylua.toml` that excludes it, StyLua returns the buffer unchanged.

</Details>

<Callout kind="note" title="Permissions">
The tools run as your user, with access to your files and network, the same as if you started them from the terminal. Phantom asks before it runs a program from an extension for the first time, and asks again if the extension's manifest or the program's path changes. You can review or change the answer under Settings → Extensions.
</Callout>
